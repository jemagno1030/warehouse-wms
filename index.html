The Shipper CASE barcode identifies the Shipper product only. Every physical incoming box receives its own internal SB number and its contents are encoded fresh for this delivery.

Important: Contents are not copied from earlier deliveries. The same Shipper CASE barcode may contain different SKUs, quantities, and expiry dates every time it arrives.

Administrative Pause

Temporarily prevent stock-changing operations on every connected device.

How it behaves

The pause and resume codes are different. The database validates them securely; the codes are not stored in this website.

Administrative Pause blocks put-away, picking, transfers, and Admin/Owner corrections. Viewing reports remains available.

Change the two placeholder codes in supabase-schema.sql before running it.

FULL WMS DATA RESET

Owner only. Permanently clears all warehouse/master/history data and deletes every non-Owner user account.

Destructive operation. Current inventory, SKU Masterlist, Containers, Shipper Boxes, Sales Orders, Transaction History, System Audit Events, Non-FEFO records, rack locks, and all non-Owner accounts will be removed. Owner accounts, rack locations, System Control configuration, System Manager/Cron, and database structure are preserved.

Create and verify a current V2.1 backup before using Full Reset. The reset leaves the WMS in Administrative Pause.
